---
title: Store selection
description: Choosing the active Store after sign-in.
---

The Store selection page lists the Stores the User can access as a grid of cards.

- A card shows the Store image when one is set, otherwise a placeholder icon. Store images cannot be uploaded from the app.
- An empty state is shown when the User has no accessible Store.
- The selected Store becomes the **active Store**. It is kept across page reloads in the browser's local storage.
- After selection, the User goes to the [Menu](/pizzahub-docs/features/menu/) if the Menu is not ready yet, otherwise to the [Tableau](/pizzahub-docs/features/tableau/).

The active Store name is shown in the header on every page.
